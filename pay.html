🛡️ Gestion des erreurs

❌ Types d'erreurs
  • • Écart de montant (paid_sum ≠ Σprime)
  • • Facture manquante dans NSIL
  • • Doublon (RefComptable existant)
  • • Exception SQL / Timeout
🔄 Actions en cas d'erreur
  • • Rollback → Annulation transaction
  • • estMigre = 2 → Paiement en erreur
  • • Log → Détail + stack trace
  • • Reprise → Prochain batch
⚠️ Principe : En cas d'erreur, AUCUNE modification n'est persistée. Le paiement reste en attente ou passe en erreur pour reprise.
